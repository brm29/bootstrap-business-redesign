# Bootstrap Business Redesign

A Bootstrap 5 redesign concept for AllyCats Hair Studio's website, built as a team coding project.

> This is an unaffiliated student redesign concept.


## Getting started
Just open `index.html` in your browser. No build tools or installation required.
